第 1 关 · 看图排顺序

跳起来吃鱼

旗子旁边，小猫想先跳起来，再吃鱼。

邀请他先指一指：哪张卡应该排在前面？

看看一种编法

按 1、3，再按空格。上面是目标，下面是自己编的。

第 2 关 · 发现并修正错误

修好节目

小猫学了一段不太对的节目。先演给自己看。

让他用手指停在两排开始不同的位置，再问：最后一张怎么拿掉？

看看一种编法

先按空格。用 Del 拿掉最后的跳，再按 3、1，最后按空格。

第 3 关 · 让一段动作重复

双拍合奏

旗子后有四个动作，手里只有三张卡的位置。

遮住后半排，让孩子找出重复出现的那一小段。

看看一种编法

按 1、2、R，再按空格。两张卡会按原顺序演两遍。

第 4 关 · 看完再编

回声山谷

问号挡住了动作。按 H 再看小猫演一遍，试着把记住的动作排回来。

可以边看边用手模仿，忘了就重看，不用猜次数。

看看一种编法

这段是吃鱼、跳、唱。按 3、1、2，再按空格。

第 5 关 · 给小猫规划路线

鱼塘寻宝

从鱼塘左下角出发，到右上角取鱼。这一关的 1 是向上，2 是向右，3 是取鱼。

让他先用手指走一条路，再找另一条也到鱼的路线。

看看一种编法

1、2、3 和 2、1、3 都能取到鱼。最后按空格走自己的路线。

第 6 关 · 用事件开演

摇摇舞会

让小猫唱、跳，再唱、跳。排完动作还要给它一个开始信号。

先只按空格观察：小猫在等谁？让孩子决定舞会何时开始。

看看一种编法

按 2、1、R、空格。拿稳掌机轻摇一下，或按 S。网页版点「摇一摇」。

一起玩

家长坐在旁边时

第一轮，你只指图

指着旗子问：“你猜小猫先做什么？”让孩子选卡、按空格。演错了，把两排图放在一起看，先找哪里不同，再让他决定改哪张。

第二轮，轮流当导演

一人编两张卡，另一人先用身体演一遍，再让小猫来演。轮到孩子出题时，大人也可以猜错，让孩子教回来。

第三轮，留下他的作品

在掌机按 0 回选关，再按 0 开自由剧场。A、B、C 各存一个节目。改完自动保存，下次开机还能演。

掌机按键小抄
1 / 2 / 3
跳、唱、吃鱼。鱼塘里改为上、右、取鱼。最多三张卡。
空格 / 回车
运行。得星后去下一关。第六关先准备，再轻摇掌机或按 S。
Del · R · H
撤回最后一张、整段演一遍或两遍、重看本关示范。
0 · A / B / C
0 返回选关页，按 1–6 选关或 0 进入自由剧场。字母键切换自由节目册。

看看玩法从哪里来

ScratchJr 的活动让角色通过动作、声音和重复来跳舞，小猫把这几个概念缩成三张动作卡。鱼塘借鉴了 Sphero indi 用路线任务试验不同走法的思路。关卡和掌机画面为本项目制作。
